# SEO checklist (ChooseTools)

## Canonical
- Canonical host: `https://www.choosetools.com` (SITE_URL in `src/lib/tools.ts`).
- Redirects (hosting/dashboard, Owner action): 301 `http` → `https` and apex → `www` in one hop.

## Indexable locales
- `INDEXABLE_LOCALES` in `src/lib/indexing.ts`: `en`, `ar`, `nl`, `es`.
- Other locales are `noindex, follow` and excluded from sitemap/hreflang until native review.

## Sitemap
- URL: `https://www.choosetools.com/sitemap.xml`
- Generated by `app/sitemap.ts` from the same route list the site renders.
- Only indexable locales × (111 tool/static pages + home). No blog URLs while `INDEXABLE_BLOG_SLUGS` is empty.
- Each entry carries `xhtml:link` alternates for the 4 indexed locales + `x-default`.
- `lastmod` from `lastModified()` (content date), not build time.

## How to run the sitemap check
- `npm run build` then `node scripts/check-links.mjs` (validates internal links resolve).
- To validate sitemap URLs: fetch each URL from the built/preview site; fail on non-200, redirect, `noindex`, or canonical mismatch.

## Manual steps for the Owner in Search Console
1. Inspect and request indexing for the home page and the top-20 tools.
2. Re-validate "Page with redirect" after T11/T12 deploy.
3. Submit the updated sitemap.
4. Do not call any Google API from the app.
